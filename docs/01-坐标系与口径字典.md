# 01 坐标系与口径字典

所有指标都必须落在统一坐标系 **战场 × 规模档 × 时间** 上。本文定义每个维度的口径，以及全体系通用的术语。口径有变更时，以本文为准，并走第 08 篇的变更流程。

---

## 一、战场

**范围**：消金、信贷、支付、保险四个战场。其中 antom 是四个战场之一，使用自有的项目管理系统，通过接口同步到 iSmart。

| 对象 | 归属规则 |
|---|---|
| 人日 | **人属于哪个战场，人日就归哪个战场**。以 HR / PMO 名册中的所属战场为准 |
| 需求 | 按 iSmart 需求主档的战场字段归属 |
| 跨战场需求 | 拆成各战场各自的需求，分别计入各战场的吞吐。原始业务需求保留"父需求 ID"，只用来看端到端周期，**不重复计入吞吐** |

---

## 二、规模档

**档位**：XS / S / M / L。

**定档来源**有两种，每个需求都必须标明自己用的是哪一种：

| 定档来源 | 适用条件 | 特点 |
|---|---|---|
| **大模型档**（主口径） | 所在战场的知识库已达就绪标准，且该需求文档充分 | 读需求文档提取规模要素，不随效能漂移。详见第 02 篇 |
| **TL 兜底档** | 知识库未就绪，或文档不足 | 使用 TL 排期时填写的评估人日档。AI 提效后会逐渐下漂，**效率偏保守** |

**原则**
- 档位一旦判定即冻结，不随实际人日变化而调整。
- 实际人日只作为结果，不参与定档。
- 跨战场比较时，如果两个战场的定档来源不同，看板必须提示口径差异。

## 三、时间

### 3.1 两个口径

| 口径 | 归属时点 | 用途 |
|---|---|---|
| **承诺口径** | 排期月（以月初冻结快照为准） | 业务方关心的"答应的交了没有"：当月兑现率、M+1 / M+2 累计兑现率 |
| **产出口径** | 上线月（以生产发布记录的日期为准） | 效能分析：吞吐当量、效率指数、研发周期 |

两个口径每月用桥接表打通，见第 07 篇。

### 3.2 时间定义

| 名称 | 定义 |
|---|---|
| 周 | 周一至周日 |
| 月 | 自然月 |
| 工作日 | 按公司日历，扣除法定节假日 |
| 上线日 | 该需求**最后一次生产发布**的日期，以发布系统记录为准；没有发布记录挂接时，暂以 iSmart 实际上线日为准，并打标记 |
| 排期冻结日 | 每月第 3 个工作日。冻结后快照不可修改，月内调整记为"插入"或"移出" |
| 滚动 3 个月 | 包含当月在内的最近 3 个自然月。效能结论（效率指数、等效人力）一律用这个窗口；月度数字只看趋势 |

### 3.3 基线期

- **定义**：AI 工具大规模推广前连续 6 个月。
- **起止月份**：待确认后填写于此：`____年__月 – ____年__月`。
- **用途**：校准大模型定档的权重、计算 k 值、作为效率指数 1.00 的参照。

## 四、需求单元

| 项目 | 口径 |
|---|---|
| 统计单元 | iSmart 中的一个需求 ID |
| 纳入吞吐 | 业务需求、技术需求（默认口径，可按实际类型调整） |
| 不纳入吞吐 | 生产缺陷修复、运维事务、咨询支持。这些工作消耗的人日仍计入名册可用人日，体现在"有效工时占比"上 |
| 已上线 | 以生产发布记录为准（见第 04 篇字段级权威源表） |
| 取消 | 状态为"已取消"的需求不计吞吐；若已投入工时，计入在制的"取消 / 移出" |

---

## 五、资源

| 项目 | 口径 |
|---|---|
| 资源类别 | 正式、数马。外包本月裁撤完毕，只在历史期作为单独类别保留 |
| 名册可用人日 | Σ 每人每月在册的工作日。月中入职、离职、裁撤的按实际在册天数计算；不扣请假 |
| 名册来源 | HR / PMO 月表，经 V5 与 iSmart 报工人员对账后使用 |

## 六、术语表

| 术语 | 解释 |
|---|---|
| 规模要素 | 描述"需求要做什么"的可数项：涉及系统数、接口变更数、页面 / 交互数、外部协同方数、是否新业务 |
| 要素分 | 规模要素按固定权重加权得到的分数 |
| 需求当量 | 要素分 × k，单位是"基线等价人日"，即按 AI 之前的平均效率完成这个需求需要多少人日 |
| k 值 | 换算系数，使基线期效率指数正好等于 1.00 |
| 尺子 | 固定的模型版本 + 提示词版本 + 知识库快照版本。三者任一变化都算"换尺子" |
| 效率指数 | Σ 上线需求当量 ÷ Σ 名册可用人日 |
| AI 同期提效人日 | Σ 当量 − Σ 名册可用人日。大于 0 表示比基线效率多交付的活 |
| 等效人力 | 月均提效人日 ÷ 月工作日，即"AI 顶了几个人" |
| 应交池 | 月初排期冻结快照中的需求集合 |
| 在制 | 已排期或已插入、尚未上线也未取消的需求 |
| 开发中在制 | 在制中处于开发、测试状态的需求，用于利特尔定律校验 |
| 桥接表 | 每月把承诺口径和产出口径对齐的存量 / 流量表 |
| 就绪等级 | 结论级 / 底数级 / 不出，标明一个指标当前能否下结论 |
| 定档来源 | 大模型档 / TL 兜底档 |
| 知识库就绪 | 某战场的知识库达到第 02 篇规定的三条标准 |
